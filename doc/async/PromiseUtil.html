delayChain(ms)indextop

Return a function which takes a value and returns a promise that will resolve to the value after the specified number of milliseconds. This is useable directly in a promise chain to cause a delay and pass on the resolution value.

Arguments & Return:

 ms              Milliseconds to delay.
 =>              A function for a `then` on-resolve argument.
