Ultraviolet vDOM Engine

The Ultraviolet package provides a module for generating virtual-DOM descriptions, and rendering those description as DOM trees (which can then be mounted into the browser). This is a genuine microlib weighing in at under 500 LOC (sans documentation comments), under 6K compiler-minimized, and under 3K compressed.
